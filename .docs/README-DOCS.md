# banyuMall 项目文档管理指南

**项目名称**: banyuMall  
**创建时间**: 2025-08-12 10:04:51  
**文档版本**: v1.0.0  
**管理机制**: 双重管理（文档持久化 + 记忆驱动）

## 核心管理原则

### 双重管理机制
- **文档持久化**: 对用户可见的项目状态和规则
- **记忆驱动**: 对AI可见的智能决策和经验库
- **双重更新**: 每次任务完成后同时更新文档和记忆

## 项目基本信息

### 技术架构
- **框架**: Spring Boot 微服务架构
- **模块结构**:
  - `core/`: 核心业务模块
  - `service/`: 服务层模块
  - `third-party/`: 第三方集成模块

### 核心模块
1. **core-publisher**: 发布者核心业务
2. **service-auth**: 认证服务
3. **service-user**: 用户服务
4. **service-gateway**: 网关服务
5. **third-party-wechatWork**: 企业微信集成
6. **third-party-aliyunOss**: 阿里云OSS集成

## 开发规则

### 代码规范
- 遵循Java编码规范
- 使用camelCase命名
- 模块化设计，职责分离

### 文档规范
- 所有重要变更必须更新文档
- 使用标准化模板
- 保持文档与代码同步

### 记忆管理
- 基于OBS-V1 v2标准格式
- 分类存储：项目记忆、规则记忆、业务记忆、状态记忆、关系记忆
- 实时同步更新

## 任务执行流程

### 通道分类
1. **零仪式通道**: 纯文本修改，直接执行
2. **快速通道**: 单一文件修改，基于经验执行
3. **标准通道**: 多文件修改，需要测试验证
4. **提案驱动流程**: 架构级变更，需要设计决策

### 双重更新要求
- 每次任务完成后必须更新文档和记忆
- 检测并解决文档与代码的不一致
- 萃取经验，沉淀规则
